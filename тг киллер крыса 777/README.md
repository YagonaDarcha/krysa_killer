# Бот ивента 777

## Запуск
1. `pip install -r requirements.txt`
2. В `.env` — `BOT_TOKEN` и `ADMIN_IDS` (свой ID можно узнать командой /id в личке бота).
3. Запусти `run.bat`: он держит бота 24/7 и перезапускает его, если тот упадёт. Можно и просто `python bot.py`.
4. Добавь бота в группу **админом** с правами «Блокировка пользователей» и «Удаление сообщений».
5. В группе: `/event_start`. Или в личке: `/admin` → Чаты и ивенты → чат → «Ивент: ВКЛ».

## Команды
Группа: `/spin` (или просто отправить 🎰), `/lives`, `/me`, `/top`, `/rules`, `/event_start`, `/event_stop`.
Личка: `/admin`, `/reward` (для чемпиона), `/id`, `/rules`.

## Премиум-эмодзи
Все эмодзи лежат в `app/emoji.py`: `"ключ": ("ID", "запасной эмодзи")`.
Чтобы узнать ID, отправь премиум-эмодзи боту в личку с аккаунта админа — он ответит его ID.
Вставь ID в файл и перезапусти бота. Если ID пустой, бот показывает обычный эмодзи.

## Хранение
Все настройки, игроки и чемпионы хранятся в `data/game.db` (SQLite), поэтому после перезапуска ничего не теряется.
Лог пишется в `bot.log`.
